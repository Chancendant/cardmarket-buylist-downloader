# Cardmarket Wants Exporter

A lightweight Chrome extension that allows you to download your Cardmarket "Wants" lists as CSV files with a single click.

## Features
* **One-Click Export:** Instantly scrape card names from your active Wants list.
* **Clean Data:** Generates a standard CSV file containing only the card names.
* **Easy Integration:** Works directly within the Cardmarket interface.

## Installation Instructions

Follow these steps to install the extension in Google Chrome:

1. Download the project as a `.zip` file from this repository.
2. Unzip the downloaded folder to a location on your computer.
3. In your Chrome browser address bar, type: "chrome://extensions"
4. Toggle Developer mode (top right)
5. Click "Load unpacked"
6. Select the extracted folder
7. Extension appears in the toolbar
